In full screen the browser may keep Esc for itself (hold Esc to leave full screen where the browser allows the game to have it). Settings (F10, the settings button, or "Port settings" on the game's menu screen) are remembered in this browser. The saves button downloads and uploads the save slots. Alt+X (exit) does nothing here; some browsers keep a few Alt keys for themselves (e.g. Alt+digit switches tabs on Linux, Alt+F / Alt+E open the browser menu on Windows).
